# 📝 Blog Platform with Comments

A full-stack blogging platform developed as part of my internship at **Thiranex Technologies**. The platform enables users to register, authenticate, create blog posts, and engage with content through an interactive commenting system.

This project was built to demonstrate practical knowledge of full-stack web development, RESTful API design, authentication mechanisms, content management, and user interaction features.

## 🏢 Internship Information

**Organization:** Thiranex Technologies

**Project Title:** Blog Platform with Comments

**Objective:** Develop a blogging platform where users can create, manage, and interact with blog content through a secure authentication system and comment-based discussions.

### Key Features Implemented

* User Registration and Login
* JWT Authentication
* Password Encryption using bcryptjs
* Create, Read, Update, and Delete (CRUD) Blog Posts
* Interactive Comment System
* RESTful API Development
* Backend Data Management
* Frontend and Backend Integration

### Expected Learning Outcomes Achieved

* Full-Stack Development
* Authentication & Authorization
* REST API Design
* Content Management Systems
* User Interaction Features
* Database Integration Concepts
* Client-Server Architecture
